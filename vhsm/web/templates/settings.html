Scheduled updates

Once a day at the chosen time the manager checks Steam for a new build and, if there is one, installs it. Running instances are stopped first and started again afterwards, so pick an hour when the servers are quiet.

Server address

The hostname or IP players connect to. It is shown beside each instance and is what the reachability check probes, so it should be what players actually type — a public DNS name or IP, not this machine's internal address. Leave it blank to use the detected address, which is right on a LAN.
